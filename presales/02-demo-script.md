# 三分钟 Demo 脚本

> 演示对象：客户技术负责人 + 业务负责人
> 演示载体：`report.html`（本项目生成的竞品与趋势报告）+ `data/capability_matrix.csv`
> 原则：**先给结论，再给证据，最后给可复现的方法**。全程不念 PPT。

---

## 0:00–0:30　开场（结论先行）

> "今天不讲设备参数。我用三分钟给您看两张东西：第一张是**同类厂商在同口径下的能力对比**，第二张是**我们凭什么在这个口径下领先**。所有数据都能溯源，您随时可以质疑某一条。"

**动作**：打开 `report.html` 首页，指向场景画像区域。

## 0:30–1:20　第一张：能力矩阵（我们怎么比较）

> "这张表的比较口径不是我们自己定的，是**按您这类项目的招标要求反推的**：必须支持的标准、必须覆盖的行业、是否要求宽带与公专融合。
> 您看第一列——五家厂商里，同时具备窄带自主标准（PDT）和宽带演进能力的只有两家。**这不是能力炫耀，这是准入问题**：只有窄带的厂商，连技术标的第一关都过不了。"

**动作**：指向排名表与各维度条形图；说明缺失字段按 0 计（"我宁可低估自己，也不用行业均值把表格填满"）。

## 1:20–2:10　第二张：差异化与风险（我们不藏短板）

> "第二张是**相对基准厂商的差距**，包括我们自己落后的项。比如 AI 能力，全行业 9 家厂商里只有 1 家有可公开引用的 AI 战略表述，覆盖率 33%——**这个行业的 AI 目前是叙事，不是落地**。
> 所以我们不跟您承诺'智能体'，我们只承诺三个可测指标：语音指令识别准确率、指令下发时延、事件留痕完整率。达不到，不写进验收条款。"

**动作**：切到报告第 3 节差距分析 + 第 5 节数据质量（覆盖率 33%、来源 9/9）。

## 2:10–2:50　方法的可复现性（最关键的一段）

> "这套分析不是 PPT 做出来的。它是一条流水线：**采集公开信息 → 结构化字段校验 → 抽取与归因 → 按场景打分 → 出报告**。
> 您给我一份你们真实的招标文件，我把场景画像换掉，**两小时内出一版针对您项目口径的对比**。数据缺的地方会显式标 unknown，不会用估算值糊过去。"

**动作**：展示 `src/` 目录结构，或现场跑一条命令：

```bash
python src/score.py && python src/report.py
```

## 2:50–3:00　收尾（给出唯一下一步）

> "下一步只需要您做一件事：**给我一份真实项目的技术要求**，我把它变成可对比的口径。如果对比结果对我们不利，我也会如实告诉您——因为方案要能交付，不能靠话术。"

---

## 演练要点（自己背下来）

- 被问"数据从哪来" → 指向 `data/sources.md`，说明**多口径并列、不择优呈现**。
- 被问"AI 你们到底做到什么程度" → 只答三个可测指标，**不要升级承诺**。
- 被问"和摩托罗拉比呢" → 不比品牌，比"标准自主 + 总拥有成本 + 利旧对接"。
- 被问"这套报告是你做的？" → 答"是我自己搭的流水线，代码和来源都在仓库里，您可以让人复核"。
