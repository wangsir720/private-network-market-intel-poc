## 二、四类厂商的差异化定位

### 1. 标准全覆盖型：海能达
- 同时掌握 TETRA / DMR / PDT，是 PDT 标准核心起草单位；370MHz 应急专网主力供应商（S2、S4）。
- 国内专业市场约 35.7% 第一；全球约 13% 第二（招商证券口径）（S1、S2）。
- 已有"AI 专网"战略与基于大模型的智能终端表述（S1、S4）。
- **风险**：2023–2025 与摩托罗拉的专利纠纷导致累计亏损超 41 亿元（公开媒体口径），2025-01 达成全球和解（S5）。财务承压会进入客户尽调清单。
- **打单话术**：标准自主（PDT）+ 利旧能力 + 应急实战案例（国家级演习保障）。

### 2. 高端标准型：摩托罗拉系统
- TETRA / P25 全球主导，北美欧洲公共安全市场壁垒极强；中国区约 25% 份额（S1、S3）。
- **弱点**：不是中国自主标准（PDT），在国产化替代背景下承压；价格定位高。
- **启示**：不要跟它比"高端品牌"，要比**标准适配 + 总拥有成本**。

### 3. 区域/细分型：建伍、Tait、欧宇航
- 建伍：工业防爆约 23% 全球份额，靠可靠性与认证壁垒（S1）。
- Tait：公共安全与公用事业区域优势（S1）。
- 欧宇航：欧洲 TETRA 主力，中国受 PDT 替代影响（S3、S4）。
- **启示**：竞争中真正的护城河是**资质与行业场景沉淀**，不是参数表。

### 4. 新入局/生态型：中国通号、遨游通讯
- 中国通号："轨交 + 低空"双赛道，6G 无蜂窝通信研发，低空应急通信实测百公里通联（S5）——**用轨交现金流养新赛道**。
- 遨游通讯：与吉利时空道宇合作发布双卫星终端（天通 + 低轨/北斗短报文）（S5）。
- **启示**：竞争边界正在从"对讲机厂商之间的竞争"变成"通信、轨交、卫星、无人机玩家的融合竞争"。售前需要理解**跨域集成**，而不是只讲终端参数。

## 三、三个可复用的分析结论

1. **标准覆盖是政企准入的硬门槛**：只有窄带（PDT/DMR）没有宽带（LTE/5G）的厂商，拿不下"综合解决方案"类标的。
2. **AI 能力目前是"叙事差异"，不是"落地差异"**：9 家厂商中只有 1 家（海能达）有可引用的 AI 战略表述，`ai_features` 覆盖率仅 33%。谁先做出可验证的场景指标，谁就先建立真实壁垒。
3. **利旧与总拥有成本是客户真正的决策变量**：政策推动了频率费标准化与 5G 专网试点，客户开始算全生命周期账。
