# 专网通信行业趋势与政策观察

> 数据截至 2026-09-28，来源编号对应 `data/sources.md`。
> 本文只做**公开信息的结构化归纳**，不做投资建议、不代表任何厂商口径。

## 一句话结论

专网通信正从"卖终端"转向"交解决方案"：**窄带是存量基本盘，宽带智能专网是增量与高毛利方向**，而 AI 的价值承诺（感知—传输—决策—执行闭环）目前**叙事领先于落地**——这正是方案侧能做出差异化的地方。

---

## 一、政策与标准

### 1. 工业 5G 独立专网进入标准化试点
五部门联合发文启动工业 5G 独立专网试点，面向高端制造、矿业、电力、港口、医疗等领域；试点需取得频率使用许可，技术方案须符合 T/CCSA 858-2026《工业 5G 独立专网 总体技术要求》（S5）。

**对售前的含义**：客户会问"我的窄带专网要不要推倒重来"。答案不是二选一，而是**利旧 + 平滑演进**——方案里必须写清既有投资如何保护。

### 2. 频率占用费标准明确
发改委、财政部相关通知执行，首次明确 5G-R 铁路专用无线通信、工业专网、无人驾驶航空器、宽带数字集群通信的收费标准（S5）。

**对售前的含义**：专网从"建设"走向"标准化运营"，全生命周期成本可测算。**成本收益表从加分项变成必答项。**

### 3. PDT 是中国公安/应急的主推窄带标准
PDT 2012 年定为部标、2014 年 TETRA 相关部标废止；应急管理部推动 370MHz PDT 窄带集群建设（上行 372.0875–375.8125MHz，下行 380–383MHz），建设层级由省级下沉到地市、乡镇（S4、S5）。

**对售前的含义**：
- 公安与应急是刚性基本盘，标准壁垒明确（国产自主标准）；
- 县级/乡镇级的设备配置标准、价格敏感度、运维模式与省级不同 → **渠道下沉与低成本终端组合是竞争关键**。

### 4. "十五五"把安全应急产业提到战略高度
公开表述提出专网从"基础建设"向"智慧韧性"转变，行业重心从"提供工具"转向"构建安全底座"（S4、S6）。

**对售前的含义**：给客户讲"通信管道"已经不够，要讲**安全底座**与业务连续性。

## 二、技术路线

| 方向 | 现状 | 判断 |
|---|---|---|
| 窄带存量 | 技术成熟、同质化、价格竞争（S3、S6） | 基本盘，靠渠道与成本守 |
| 宽带智能专网 | 5G 独立专网、LTE 宽带专网、宽窄带融合平台、AI 智能调度、专网算力终端（S3） | 增量与高毛利来源，靠交付能力抢 |
| 公专融合 | 传统专网与公网 PoC 边界模糊；4G/5G 公网对讲在轻调度场景普及（S1、S4） | 客户已有的 370MHz 网络能否利旧对接，成为采购门槛 |
| AI 化 | 从语音降噪、智能调度延伸到基于大模型的智能终端；行业提出"AI 专网"（S1、S4） | **叙事领先于落地**，谁能翻译成业务价值谁占优 |
| 空天地一体化 | 双卫星终端出现；低空应急通信实测百公里通联，含机载 PDT 基站（S5） | 改写应急组网逻辑，终端"无缝接入"成新门槛 |
| 防爆/极端环境 | ATEX、IECEx 认证门槛提高（S1） | 资质即壁垒，头部厂商优势扩大 |

## 三、需求结构

1. **从单一主导到多元驱动**：政务应急 + 工业能源 + 交通基建 + 智慧城市 + 军工特种（S3、S6）。
2. **存量升级是主要订单来源**：早期窄带系统进入替换周期（S6）。
3. **中小企业客户开始放量**：成本下降推动需求觉醒，标准化产品组合与渠道下沉决定获取效率（S6）。
4. **需求侧指标变化**：从单一语音对讲，转向视频回传、数据上报、智能调度、全域联动（S3）。

## 四、对方案与产品侧的三条实践含义

1. **方案要带"利旧"章节**：不讲利旧的方案在本轮周期里会被直接问倒。
2. **价值量化必须双边**：既算客户省多少（人力、响应时间），也算合规与留痕（等保、应急演练记录）。
3. **AI 要落到场景**：把"大模型"翻译成"指令识别准确率、调度指令下发时延、多源信息融合速度"，而不是停留在"我们也有 AI"。
