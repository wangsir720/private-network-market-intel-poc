# 产品定位建议（面向产品规划）

> 用途：把能力矩阵与趋势情报，翻译成**产品规划可用的输入**。
> 回答的问题：如何用市场调研与竞品分析的结果，支撑产品规划与市场目标。
> 性质：个人基于公开信息的分析练习，非任何厂商官方规划。

---

## 一、定位主张

**"窄带守基本盘、宽带抢增量、AI 做差异、利旧当卖点。"**

理由：
1. 窄带（PDT/DMR/TETRA）是存量基本盘，需求来自公安/应急的刚性替换周期，**不能丢但也不该是主要投入方向**（S3、S6）；
2. 增量与高毛利在宽带智能专网（5G 独立专网、LTE 宽带专网、宽窄带融合平台、AI 智能调度），但需要"全套解决方案交付能力"，供给稀缺（S3）；
3. AI 目前是叙事差异——9 家厂商里仅 1 家有可引用的 AI 战略表述（`data/vendors.json`），**先做出可验证指标的一方将建立真实壁垒**；
4. 政策已明确频率费与 5G 专网试点规则（S5），客户的决策变量从"设备单价"转向"全生命周期成本"，**利旧对接能力**成为方案准入项。

## 二、细分市场优先级

| 优先级 | 细分 | 判断依据 | 产品动作 |
|---|---|---|---|
| P0 | 应急管理（370MHz PDT 升级与下沉） | 政策主推 + 建设层级下沉到乡镇（S4、S5） | 乡镇级低成本终端组合 + 统一网管；做"利旧升级"标准方案包 |
| P0 | 公安（存量系统升级） | PDT 为部标、国内份额基础稳固（S2、S4） | 宽窄带融合演进路线图；数据上报与视频回传能力补齐 |
| P1 | 工业能源（防爆 + 工业 5G 专网） | 5G 独立专网试点 + 防爆认证壁垒（S1、S5） | 防爆终端认证矩阵；与工业 5G 专网对接方案 |
| P1 | 轨道交通（宽窄带融合） | 存量窄带升级周期（S6） | 与既有 TETRA/信号系统共存的过渡方案 |
| P2 | 低空/空天地一体化 | 低空应急通联突破、双卫星终端出现（S5） | 关注生态合作（机载基站接入、多模终端）而非自研全部 |

## 三、三个可执行的规划输入

### 1. 建立"利旧对接能力"字段并纳入产品准入门槛
现状：能力矩阵中没有任何厂商披露"利旧对接"能力，客户却在招标里必问。
动作：把"是否支持与既有 370MHz 专网 / TETRA 系统共存"做成产品级指标，对外可查。

### 2. 把 AI 能力从"叙事"改成"可验证指标"
现状：`ai_features` 覆盖率 33%，且表述均为战略级（无量化）。
动作：定义 3 个可测指标——**语音指令识别准确率、调度指令下发时延、多源信息融合处理速度**，并在 POC 中给出基线值。

### 3. 针对乡镇级市场做"低成本 + 易运维"产品组合
现状：建设层级下沉到乡镇，配置标准、价格敏感度、运维模式与省级不同（S5）。
动作：形成标准化的"乡镇一套"配置清单，降低售前方案定制成本，也便于渠道下沉。

## 五、前提与假设（必须显式声明）

1. 判断基于**公开信息**，份额存在多口径，未做统一；
2. 场景画像为示意（省市级应急通信），真实项目需替换为客户招标文件要求；
3. 未覆盖军用/涉密方向；
4. 本文件是**分析练习**，不代表任何厂商的实际规划。
